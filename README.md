Sales & Revenue Analysis Dashboard

📌 Project Overview

The Sales & Revenue Analysis Dashboard is a Python-based data analysis project that analyzes sales data and generates visual reports.

This project helps understand product-wise revenue and region-wise revenue using data analysis and visualization techniques.

🎯 Project Objectives

- Analyze sales data using Python.
- Calculate total sales and total revenue.
- Identify the highest revenue-generating product.
- Compare revenue across different regions.
- Generate charts for better visualization.

🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- VS Code

📂 Project Files

- "analysis.py" – Python source code.
- "sales_data.csv" – Sales dataset.
- "product_revenue.png" – Product-wise revenue chart.
- "region_revenue.png" – Region-wise revenue chart.

📊 Project Results

- Total Sales: 28
- Total Revenue: ₹2,32,500
- Highest Revenue Product: Laptop
- Highest Revenue Region: Chennai
